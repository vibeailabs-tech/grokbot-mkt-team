# Skill nào cho Bot nào

Repo trên máy là nguồn. Bot làm theo file, không theo trí nhớ khi hai bên khác nhau. Não công ty nằm ở `company/`, không nằm trong thư mục skill.

| Bot | Đọc trước mỗi việc |
|---|---|
| Lead | `skills/mkt-plan/SKILL.md`, `references.md` |
| Research | `mkt-brand-kb`, rồi `mkt-brief`. Audit thêm `mkt-audit`, `mkt-page-scan`, `mkt-competitors` |
| Content | `mkt-brand-kb`, `company/vi-du.md`, rồi `mkt-social`, `mkt-emails`, `mkt-copy`, hoặc `mkt-ads` |
| SEO | `mkt-brand-kb`, rồi `mkt-seo`. Sửa trang thì thêm `mkt-copy` |
| Report | `mkt-report`, `company/so-lieu.md` |
| Review | `mkt-brand-kb`, rồi `mkt-review-check` |

`mkt-ads` không phải bot riêng. Chỉ chạy khi người yêu cầu bản nháp chữ và không kèm lệnh chi.
